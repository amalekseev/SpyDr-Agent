Название теста: Проверка расчета ставки калькулятором Calc
Предусловия: Имеется доступ к REST API сервера "calc_hierarchy_service"; подготовлен файл запроса calc_request.json с корректными данными для расчета.
Шаги:
1. Сгенерировать уникальный идентификатор запроса (traceId).
2. Установить параметр "enableFeature" в значение "No".
3. Отправить POST-запрос на адрес /calc?calculatorName=Calc сервера "calc_hierarchy_service", используя тело запроса из файла calc_request.json.
4. Проверить, что сервер вернул успешный ответ (код 200).
5. В теле ответа убедиться, что поле "traceId" совпадает с отправленным уникальным идентификатором запроса.
6. В разделе "outAttributes" убедиться, что присутствует параметр "rateAdjustment" и сохранить его значение.
7. Вывести сообщение "Проверка бизнес-логики расчета" (информационный шаг).

Ожидаемый результат:
- Сервер возвращает успешный ответ с кодом 200.
- В теле ответа поле "traceId" совпадает с отправленным идентификатором.
- В разделе "outAttributes" присутствует параметр "rateAdjustment" с числовым значением.

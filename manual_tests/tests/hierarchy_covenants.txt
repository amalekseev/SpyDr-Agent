Шаг 1: Присвоить переменной "traceId" уникальное значение UUID.

Шаг 2: Установить значение переменной "enableFeature" как "No".

Шаг 3: Отправить POST запрос на конечную точку /calc с параметром calculatorName=Calc на REST сервере "calc_hierarchy_service". Тело запроса взять из файла "calc_request.json".

Шаг 4: Проверить, что ответ от сервера имеет код 200 и содержит тело, в котором флаг "dont_check_array_len" равен true, а в "outAttributes" находится "rateAdjustment" с ожидаемым значением, совпадающим с переменной "${rateAdjustment_1}". Также убедиться, что "traceId" совпадает с ранее заданным значением.

Шаг 5: Выполнить проверку бизнес-логики расчета с помощью Python кода, который выводит сообщение "Проверка бизнес-логики расчета".

Название теста: [UI][Negative] Проверка экспорта отчета при пустых сущностях
Предусловия: Пользователь с учетными данными MOCK_LOGIN / MOCK_PASSWORD существует и имеет доступ к системе для формирования отчетов.
Шаги:
1. Выполнить вход в систему с логином MOCK_LOGIN и паролем MOCK_PASSWORD.
2. Сформировать отчет со следующими параметрами:
   - Начало периода: 01/01/2020
   - Конец периода: 12/31/2020
   - Рабочие дни: Календарь по умолч
   - Параметр 1: нет
   - Параметр 2: нет
   - Параметр 3: нет
   - Параметр 4: нет
   - Параметр 5: нет
   - Параметр 6: нет
   - Параметр 7: нет
   - Параметр 8: нет
3. Проверить наличие на странице div-элемента с точным текстом "Сущности не должны быть пустыми".

Ожидаемый результат:
- После попытки формирования отчета с отключенными параметрами 1-8 на странице отображается div-элемент с сообщением "Сущности не должны быть пустыми".

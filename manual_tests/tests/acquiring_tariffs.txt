Название теста: Проверка всех тарифов
Предусловия: Имеется доступ к REST API сервера "rest_mock"; подготовлены файлы запросов и ответов: request_recommended.json, response_recommended.json, request_profitability.json.
Шаги:
1. Сформировать уникальный идентификатор запроса (UUID).
2. Определить текущую дату и время в формате ГГГГ-ММ-ДДTЧЧ:ММ:СС.
3. Задать системные параметры: spName = "urn:mock:autotest", systemId = "urn:mock:system".
4. Отправить POST-запрос на адрес /mock-gateway/v1/tariffs/recommended сервера "rest_mock" с заголовками:
   - rqUid: уникальный идентификатор запроса
   - rqTm: текущая дата и время
   - spName: urn:mock:autotest
   - systemId: urn:mock:system
   В теле запроса использовать JSON из файла request_recommended.json.
5. Проверить, что сервер ответил с кодом 200 и тело ответа совпадает с эталонным JSON из файла response_recommended.json.
6. Сгенерировать уникальный номер контракта (случайное 7-значное число) и новый UUID для идентификатора запроса расчета.
7. Подготовить параметры расчета: процентное значение 0.8, лимит 1 000 000.
8. Отправить POST-запрос на адрес /mock-gateway/v1/calculation/profitability сервера "rest_mock" с заголовками:
   - rqUid: идентификатор запроса расчета
   - rqTm: текущее время
   - spName: urn:mock:autotest
   - systemId: urn:mock:system
   В теле запроса использовать JSON из файла request_profitability.json с указанными параметрами.
9. Убедиться, что ответ от сервера успешен (код 200).
10. Из заголовков ответа извлечь значение rquid — это новый идентификатор запроса (newRequestId).
11. Отправить GET-запрос на адрес /mock-gateway/v1/reports/by-uid с параметрами:
    - rqUid = newRequestId (из предыдущего шага)
    - periodBy = 0
    С заголовками, аналогичными предыдущим запросам.
12. Убедиться, что ответ успешен (код 200) и в теле ответа содержится идентификатор процесса обработки (processIdentifier).
13. Отправить GET-запрос на адрес /mock-gateway/v1/reports/by-id с параметром processId, равным идентификатору процесса из предыдущего шага, с теми же заголовками.
14. Выполнять повторные запросы в течение 60 секунд, пока не будет получен успешный ответ с кодом 200.
15. Проверить, что размер полученного файла отчёта превышает 2 килобайта.
16. Вычислить первый день текущего месяца плюс 1 год (используя relativedelta).
17. Проверить, что рассчитанный тариф прибыльности за 1 год (payback_1year) положительный (например, 0.025).
18. Проверить, что рассчитанный тариф прибыльности за 3 года (payback_3year) положительный (например, 0.018).
19. Проверить, что рекомендованный тариф равен максимуму из payback_1year и 0.02.

Ожидаемый результат:
- Запрос рекомендованных тарифов возвращает код 200 с эталонным ответом.
- Расчет прибыльности выполняется успешно, в заголовках ответа присутствует rquid.
- По идентификатору процесса доступен отчет размером более 2 килобайт.
- Тарифы прибыльности за 1 год и 3 года положительные.
- Рекомендованный тариф определяется как max(payback_1year, 0.02).

Тест 1: Проверка статистики сервиса

1. Отправьте HTTP GET запрос на URL "/service/monitoring/statistics" к REST серверу с именем "app_service".
2. Убедитесь, что ответ имеет код состояния 200.
3. Проверьте, что тело ответа содержит JSON объект, в котором присутствует структура:
   - "actionTasks" содержит объект "TaskRegenerate".
   - Внутри "TaskRegenerate" существует поле "waitingCount", которое является целым числом.

Тест 2: Проверка загрузки данных из внешнего источника

1. Подключитесь к базе данных "postgres".
2. Выполните SQL запрос для удаления записи: "DELETE FROM APP_SCHEMA.ACCOUNT_BALANCE WHERE POSITION_ID = '00001'".
3. Отправьте XML сообщение в кафку с именем "kafka_app" в топик "APP-TOPIC-ACCOUNTBALANCE". Сообщение должно содержать запись с атрибутами, включая "POSITION_ID='00001'".
4. Снова подключитесь к базе данных "postgres".
5. Выполните SQL запрос: "SELECT * FROM APP_SCHEMA.ACCOUNT_BALANCE WHERE POSITION_ID = '00001'".
6. Убедитесь, что в течение 60 секунд запрос возвращает запись, содержащую "POSITION_ID" равное "00001".

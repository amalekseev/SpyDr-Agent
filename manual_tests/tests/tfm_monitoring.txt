Название теста: Проверка статистики сервиса
Предусловия: Сервис "app_service" запущен и доступен для обработки запросов.
Шаги:
1. Отправить GET-запрос на адрес /service/monitoring/statistics сервера "app_service".
2. Проверить, что получен успешный ответ с кодом 200.
3. Убедиться, что тело ответа содержит JSON-структуру с разделом "actionTasks", внутри которого присутствует объект "TaskRegenerate" с числовым полем "waitingCount" (целое число).

Ожидаемый результат:
- Запрос выполнен успешно, получен ответ с кодом 200.
- В теле ответа присутствует структура JSON: actionTasks -> TaskRegenerate -> waitingCount (целое число).

Название теста: Проверка загрузки данных из внешнего источника
Предусловия: Имеется доступ к базе данных "postgres" с таблицей ACCOUNT_BALANCE в схеме APP_SCHEMA; доступ к Kafka-кластеру "kafka_app".
Шаги:
1. Подключиться к базе данных "postgres" и выполнить SQL-запрос: DELETE FROM APP_SCHEMA.ACCOUNT_BALANCE WHERE POSITION_ID = '00001'.
2. Отправить сообщение в Kafka "kafka_app" в топик "APP-TOPIC-ACCOUNTBALANCE" в формате XML:
   <record timestamp='2023-01-01T10:00:00.000' exchange='EXCHANGE' market='MKT' system='SYS' entity='ENTITY' interface='API' table='ACCOUNT_BALANCE' POSITION_ID='00001' />
3. Выполнить SQL-запрос: SELECT * FROM APP_SCHEMA.ACCOUNT_BALANCE WHERE POSITION_ID = '00001'.
4. В течение 60 секунд периодически повторять запрос и убедиться, что в результате появилась запись с POSITION_ID = '00001'.

Ожидаемый результат:
- Запись с POSITION_ID '00001' успешно удалена перед началом теста.
- После отправки сообщения в Kafka в течение 60 секунд в таблице ACCOUNT_BALANCE появляется запись с POSITION_ID = '00001'.

Тест: Успешное создание записи через POST

1. Установите базовый URL как "https://api.example.com".
2. Установите заголовок "Content-Type" со значением "application/json".
3. Отправьте POST запрос на "/items" с телом:
   {
     "name": "Новый элемент",
     "description": "Описание для теста"
   }
4. Убедитесь, что код ответа равен 201.
5. Проверьте, что тело ответа содержит поле "status" со значением "success".
6. Сохраните значение поля "id" из тела ответа в переменную "item_id".

Тест: Получение данных через GET

1. Установите базовый URL как "https://api.example.com".
2. Отправьте GET запрос на "/items/123".
3. Убедитесь, что код ответа равен 200.
4. Проверьте, что тело ответа содержит поле "name" со значением "Mock Item".

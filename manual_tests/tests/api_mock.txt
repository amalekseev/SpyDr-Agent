Название теста: Создание новой записи через API методом POST
Предусловия: Имеется доступ к API по адресу https://api.example.com, настроен инструмент для отправки HTTP-запросов (например, Postman или Swagger).
Шаги:
1. Открыть инструмент для отправки HTTP-запросов и установить базовый URL https://api.example.com.
2. В заголовках запроса указать Content-Type со значением application/json.
3. Подготовить тело запроса в формате JSON:
   {
     "name": "Новый элемент",
     "description": "Описание для теста"
   }
4. Отправить POST запрос на ресурс /items с подготовленным телом.
5. Проверить, что сервер вернул статус ответа 200.
6. В ответе найти поле "status" и убедиться, что его значение равно "success".
7. Сохранить значение поля "id" из ответа в переменную "item_id" для дальнейшего использования.

Ожидаемый результат:
Новая запись успешно создается, сервер возвращает статус 200, в ответе содержится поле "status" со значением "success", а также уникальный идентификатор новой записи, сохраненный в переменной "item_id".

Название теста: Получение данных записи по идентификатору через API методом GET
Предусловия: Имеется доступ к API по адресу https://api.example.com, настроен инструмент для отправки HTTP-запросов.
Шаги:
1. Открыть инструмент для отправки HTTP-запросов и установить базовый URL https://api.example.com.
2. Отправить GET запрос на ресурс /items/123.
3. Проверить, что сервер вернул статус ответа 200.
4. В теле ответа найти поле "name" и убедиться, что его значение равно "Mock Item".

Ожидаемый результат:
Запрос выполнен успешно, сервер возвращает статус 200, в теле ответа поле "name" содержит значение "Mock Item".

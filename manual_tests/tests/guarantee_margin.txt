Название теста: Расчет маржи через сервис расчетов
Предусловия: Имеется доступ к REST API сервера "calc_service"; подготовлены файлы запроса margin_req.json и ожидаемого ответа margin_res.json; имеется доступ к базе данных "postgres_dev" с таблицей APP_SCHEMA.CALC_SERVICE.
Шаги:
1. Сгенерировать уникальный идентификатор запроса (requestId).
2. Задать идентификатор расчета: calcId = "CALC-00001".
3. Отправить POST-запрос на адрес /api/v1/margin сервера "calc_service" с телом из файла margin_req.json.
4. Убедиться, что сервер вернул ответ с кодом 200 и тело ответа соответствует ожидаемому содержимому из файла margin_res.json.
5. Выполнить SQL-запрос к базе данных "postgres_dev": SELECT count(*) FROM APP_SCHEMA.CALC_SERVICE WHERE request_id = '<requestId>'.
6. В течение 60 секунд периодически повторять запрос и убедиться, что в результате возвращается ровно 1 запись.

Ожидаемый результат:
- Ответ на запрос расчета маржи содержит код 200 и тело, соответствующее файлу margin_res.json.
- В базе данных "postgres_dev" в таблице APP_SCHEMA.CALC_SERVICE в течение 60 секунд появляется ровно одна запись с указанным requestId.

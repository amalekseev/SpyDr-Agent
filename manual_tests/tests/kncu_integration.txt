Тест на интеграцию с внешним сервисом.

1. Присвоить переменной "correlationId" значение, соответствующее UUID.

2. Отправить POST запрос на сервер "external-integration" по адресу "/execute". Тело запроса взять из файла, соответствующего текущему типу. Для типа "type_a" использовать "type_a_req.json", для типа "type_b" использовать "type_b_req.json", для типа "type_c" использовать "type_c_req.json".

3. Проверить, что ответ имеет код 200.

4. Проверить, что тело ответа совпадает с содержимым файла, соответствующего текущему типу. Для типа "type_a" использовать "type_a_res.json", для типа "type_b" использовать "type_b_res.json", для типа "type_c" использовать "type_c_res.json".
